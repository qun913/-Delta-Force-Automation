# 三角洲行动 · 特勤处每日一轮

一轮要做的事：进游戏 → 特勤处 → 工作台 / 制药台 / 防具台 各收一次、再造一次 → 退出。

## 配置

```
工作台: 9x39mm BP        # 换成你想要的那档
制药台: 体能强化剂
防具台: 精英防弹背心
数量:   拉满
```

## 开工前自检

按顺序确认，任一不满足就**停**并说明原因，不要硬试：

1. 手机操控开关是开的，「DSH 手机操控」无障碍服务在运行。
2. 屏幕亮着且已解锁。熄屏会终止任务。
3. 本机引擎在正常模式（安全模式不加载手机操控）。
4. 先读一次屏幕，确认拿得到画面。拿不到就停，不要盲点。

## 硬约束

- **绝不输入密码、验证码、支付密码**。出现登录框要你填账号密码，立刻停，把屏幕交给用户。
- **不碰支付**。看到「点券 / 充值 / 商城 / 立即购买礼包」，退出这一步，不要确认。
- **每次点击前先读屏**，在画面里确认目标存在再点；找不到就重读一次，不要按记忆点。
- **连续 3 分钟没有新操作任务会自动结束**，所以不要长 sleep。等加载用“反复读屏直到出现标志物”，单次等待不超过 20 秒。
- 同一个动作连续失败 3 次就停，把当前画面报给用户。

## 状态表

每次操作后重新读屏，判断当前是哪一个状态，再决定下一步。**认不出来就停**。

| 状态 | 识别特征 | 动作 |
|---|---|---|
| 启动/过场 | 厂商 logo、公告弹窗、「点击进入」、服务器选择 | 能点的点掉（公告右上角关闭、点击进入任意处）；不认识就停 |
| 登录页 | 账号密码输入框、验证码 | **停**，交还用户 |
| 大厅 | 底部一排：仓库 / 部门 / 交易行 / 特战干员 / 特勤处 / 改枪台 | 点「特勤处」 |
| 特勤处主页 | 左上标题「特勤处」，四个台以卡片平铺 | 按下面的单台流程逐个处理 |
| 某个台·生产中 | 卡片上显示物品图标和进度/倒计时 | 不收，跳过这个台 |
| 某个台·有成品 | 卡片有「!」或可收取标识 | 进去收取，再下单 |
| 某个台·空闲 | 卡片显示「空闲中 / ＋」 | 进去下单 |
| 详情页·材料不足 | 「制造」按钮是灰的，旁边有「一键补齐」 | 点「一键补齐」，买完回到详情页 |
| 详情页·材料够 | 「制造」按钮是亮的 | 点「制造」，确认进入生产 |
| 详情页·余额/材料买不到 | 一键补齐失败、提示不足 | **停**，报告缺什么 |

## 单台流程

对工作台、制药台、防具台各做一遍，顺序不限：

1. 在特勤处主页找到这个台的卡片，点进去。
2. 有成品待收 → 先收，确认收进仓库。
3. 选配置里那个产物，数量拉满。
4. 「制造」是灰的 → 点「一键补齐」→ 买完等回到详情页 → 再确认「制造」变亮。
5. 点「制造」，确认出现生产进度，不是卡在原地。
6. 返回特勤处主页，接着下一个台。

三个台都处理完，退回大厅。

## 收尾

- 如果这一轮是定时触发的：退回大厅后按调度退出游戏，不要停在详情页。
- 如果是用户手动叫的：停在大厅，别杀进程。

```
补齐材料：<材料名> x<N>，花 <数量>

```

## 常见失败

| 现象 | 处理 |
|---|---|
| 读屏是黑的或空的 | 熄屏 / 权限掉了。停，报告 |
| 一直停在加载 | 网络慢或掉线。两轮仍不动就停 |
| 出现账号密码框 | 停，交还用户。不要试着输 |
| 一键补齐跳到没见过的页面 | 先只读屏不点，把画面描述给用户，等指示 |
| 点完没反应 | 读屏确认是否已切页；同一目标最多点 3 次 |
| 三个台有两个在造 | 正常。只处理空闲的那个，其余跳过 |
